# System Background Art (PNG / WEBP)

Drop your system-specific custom PNG or WebP artwork in this folder:
- `astrology-bg.webp` (or `astrology-bg.png`)
- `human-design-bg.webp` (or `human-design-bg.png`)
- `numerology-bg.webp` (or `numerology-bg.png`)
- `bazi-bg.webp` (or `bazi-bg.png`)
- `zi-wei-bg.webp` (or `zi-wei-bg.png`)
- `tzolkin-bg.webp` (or `tzolkin-bg.png`)

Each result page has a dedicated background layer ready to display these files with automatic fallback.
